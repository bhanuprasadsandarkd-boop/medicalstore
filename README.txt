Included:

- Suppliers
- Purchase records
- Expenses
- Employees
- Sales/profit/expense reports
- JSON backup/export/import
- Shop settings

IMPORTANT:
This is a browser/local-storage application, not a production-hosted pharmacy system.
It does not provide secure server-side authentication, multi-device synchronization,
barcode hardware integration, GST/legal compliance validation, or prescription/controlled
medicine workflows. Do not use demo passwords in production.

For production deployment, add a secure backend database, hashed passwords, HTTPS,
server-side authorization, audit logs, backups, barcode support, GST invoice rules,
prescription/regulated-medicine controls, and data retention/privacy controls.
